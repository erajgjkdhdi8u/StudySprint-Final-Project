# Study Sprint — как открыть проект и подготовиться к сдаче

**Study Sprint** — приложение Java Swing для планирования учёбы. Можно добавлять задачи, выбирать порядок, генерировать расписание и сохранять отчёты.

## IntelliJ IDEA

1. Клонируй репозиторий или скачай ZIP через GitHub.
2. Открой папку StudySprint-Final-Project в IntelliJ IDEA.
3. Выбери JDK 17 или новее.
4. Открой `src/main/java/kz/studysprint/App.java` и нажми Run около `main`.
5. Альтернатива: `run.bat` в Windows.
6. Проверка: `test.bat` (22 автоматических проверки).

При первом запуске появится пример `Exam preparation` с тремя задачами. Данные сохраняются в `data/plans.txt`.

## Распределение паттернов

| Студент | Паттерны |
|---|---|
| Ерасыл | Builder и Strategy |
| Арсен | Factory Method и Decorator |
| Абылайхан | Observer и Facade |
| Адильжан | Adapter и Bridge |

Это предложенные обязанности. Каждый участник должен самостоятельно разобраться, внести реальные изменения, протестировать код и показать его на защите.

## Что сдавать

- ZIP с исходным кодом и ссылку на общий GitHub.
- PDF-отчёт на английском, включая UML и скриншот.
- Историю реального участия и результаты тестов.
- Пройти индивидуальную защиту.

**Важно:** PDF-отчёт и PNG-диаграммы из подготовленного архива передаются для Moodle отдельно; GitHub содержит исходный Java-код и редактируемые Mermaid UML (`docs/UML_CLASS.mmd`, `docs/UML_SEQUENCE.mmd`). Обязательно укажите использование AI в отчёте.
